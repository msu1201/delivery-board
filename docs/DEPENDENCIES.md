# Dependencies and distribution

Node.js >=22. Runtime: Cytoscape.js 3.33.1 (MIT); browser tests: Playwright 1.58.2 (Apache-2.0). Exact versions and integrity hashes are pinned in package-lock.json. Dependency notices are in THIRD-PARTY-NOTICES.md. The application is MIT-licensed.

No CDN, model SDK or telemetry. Installation needs registry access or a populated npm cache. Normal viewing reads local configured files; visible pages can poll every five seconds. The browser may open user-selected external evidence links.

The GitHub preview can be downloaded and installed from source. package.json remains private to prevent accidental registry publication; this does not restrict the MIT license. No npm registry name or live hosted demo is claimed.
